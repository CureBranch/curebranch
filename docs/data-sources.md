# Published data sources

The cancer trees, the left navigation and the cancer pages use **published, public data only**.
It is kept in one build-time file, `app/data/public-cancer-data.json`. Every figure in that file
records its source, a link, the licence and the date it was retrieved. Each cancer page shows a
visible "Source:" line under each figure and links to **Sources and licenses** (`#sources`).

Published data is kept separate from patient branches. Patient-shared branch counts start at
**0**. No made-up patients appear in public views. Made-up EXAMPLE records appear only in the
"Just trying it out" demo and the example health card.

The file is refreshed by hand with `node tools/fetch-public-data.mjs` (it is not run in CI). The
list of cancers, their organ-system groups, the cBioPortal studies and the biomarkers checked are
set in `tools/public-data-catalog.mjs`. The numbers are never typed in by hand.

Not used: OncoKB (its licence does not allow commercial use without a separate agreement), AACR
Project GENIE (needs a registered login and agreement to its terms), CIViC (CC0, could be added
later).

Limits to know about:

- Trial counts depend on the condition search term. For example, cholangiocarcinoma studies are
  not all counted under "liver cancer".
- SEER has no Stat Facts page for mesothelioma or uveal melanoma, so those pages show genomics only.
- Some cancers (for example anal, small intestine, vulvar, bone, laryngeal) have no TCGA PanCancer
  Atlas study, so they show no gene figures.
- Some "biomarkers" in the FDA section are drug targets (for example CD20, CD38, BCMA) rather than
  test results; the section is titled "tied to a biomarker or target" for that reason.
